# Cheatsheets on Mathematics

This is a repository of cheatsheets on mathematical subjects.

- **Algebraic topology**: covers homology through characteristic classes, based on Fomenko & Fuchs, *Homotopical Topology* (2nd ed., Springer, 2016), Milnor & Stasheff, *Characteristic Classes*, and Mac Lane, *Categories for the Working Mathematician* (2nd ed., Springer, 1998) for the category-theoretic background. I tried to give every definition and theorem necessary to learn the basic structures of modern topology.
- **Algebraic number theory** *(in progress)*: based on MIT OpenCourseWare lecture notes and Milne's *Class Field Theory*; covers absolute values through local class field theory. Global class field theory to come.
- **Lie algebras** *(in progress)*: follows Humphreys' *Introduction to Lie Algebras and Representation Theory* (Springer, 1972). I tried to add more details so that people can understand the material better without missing steps.
- **World models** *(in progress)*: based on several papers: LeCun et al.'s tutorial on energy-based models, von Luxburg's tutorial on spectral clustering, and Bardes, Ponce & LeCun's *VICReg: Variance-Invariance-Covariance Regularization for Self-Supervised Learning*. I tried to give the basic construction of the world model in terms of its mathematical structure.
